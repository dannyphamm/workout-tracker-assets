# workout-tracker-assets

Public exercise illustration assets for [Workout Tracker](https://github.com/dannyphamm/workout-tracker).

## Layout

```
exercises/b4/{exerciseId}_{male|female}_{dark|light}.png
```

- Style: **B4** (warm skin, coral target muscle, teal plates)
- Size: 128×128 PNG
- Count: 468 exercises × 2 genders × 2 themes
